# Project

## Vision

Build the definitive craftsmanship simulation centered on premium cigar production.

## Core pillars

- **Craftsmanship:** player knowledge and deliberate choices determine quality.
- **Patience:** meaningful processes unfold over days, seasons, and years.
- **Legacy:** the farm, inventory, relationships, and reputation tell a persistent story.

## Target

- Unity 6 LTS (6000.5.4f1)
- C#
- Universal Render Pipeline
- Windows via Steam

The game should treat tobacco as an agricultural and artisanal system rather than a generic crafting ingredient. Provenance and accumulated process history are central to simulation depth.
