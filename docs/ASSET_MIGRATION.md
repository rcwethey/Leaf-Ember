# Asset migration

The FBX and PNG files under Assets/LeafEmber/Art were migrated from the original Godot prototype preserved on archive/godot-prototype.

- Exact duplicate animation copies were removed during migration.
- Godot import metadata, UIDs, scenes, project files, and C# files were not carried into Unity.
- Unity metadata files are authoritative on main after the first verified import.
- Source licensing and attribution were not documented in the original repository. Confirm the right to distribute each asset before a public build or commercial release.
